# War Project — исходники

В репозитории лежит архив `war-project-source.zip` с исходниками лаунчера и кастомного меню Minecraft 1.20.1 Forge.

- `launcher/` — Windows-лаунчер на Electron.
- `minecraft-menu/` — Forge-мод, который заменяет главное меню игры.

Модпак, готовые `.exe`, Java, кэши и пользовательские данные в архив не добавлены.
